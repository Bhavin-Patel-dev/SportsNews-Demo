# SportsNews Demo

A static sports news website built with vanilla HTML and CSS. This project demonstrates front-end web development fundamentals through a clean, structured news layout focused on sports content.

## Project Structure

```
SportsNews-Demo/
├── index.html       # Main HTML page
├── style.css        # All styling and layout
└── Assets/          # Images and media assets
```

## Tech Stack

- **HTML5** — Semantic page structure and content
- **CSS3** — Layout, typography, and visual styling

## Getting Started

No installation or build step required. Simply clone the repo and open the HTML file in your browser.

```bash
git clone https://github.com/Bhavin-Patel-dev/SportsNews-Demo.git
cd SportsNews-Demo
open index.html
```

Or just double-click `index.html` to open it directly in your browser.
